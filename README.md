# WarDogs Overlay 0.2

Windows 桌面火力计算器：C# / WPF HUD + WebView2 离线交互地图。

## 启动

打开 `app/WarDogsOverlay.exe`。发布目录自带 .NET 运行时；电脑需安装 Microsoft Edge WebView2 Runtime（开发机已具备）。默认只显示 HUD。按住标题、数字或空白区域拖动；控制面板内可切换炮种、地图和输入模式，直接读取炮位/目标或暂停。点“透明”切为三组数字与微型按钮，点“●”收为 40×40 小圆球，单击圆球展开。点齿轮即可在 HUD 内设置快捷键、大小、背景浓度，或手动输入坐标。大型地图从齿轮 → 坐标 / 工具打开。关闭主窗口仅隐藏地图；“退出应用”才会退出。

演示：`app/WarDogsOverlay.exe --demo`。演示带两组示例坐标，不读取剪贴板、不保存配置；此时 HUD/地图可交互，快捷键仍会注册。

## 输入模式

- 智能（默认）：炮位/目标动作先读取当前剪贴板，不合适或重复时转为等待；等待成功接收一次后回到就绪。炮位等待再按炮位键取消。
- 连续目标：设置炮位后每次复制坐标更新目标。
- 精确手动：仅按动作时读取。也可在主窗口/HUD 手动输入 X/Y。

快捷键可在 HUD 齿轮或主窗口独立“设置”页修改、录入、清除。初始便捷绑定：炮位 Ctrl+Alt+1、目标 Ctrl+Alt+2、停止恢复 Ctrl+Alt+P、HUD Ctrl+Alt+H、模式 Ctrl+Alt+M、地图 Ctrl+Alt+G。冲突只显示在近期提示，不弹窗。

坐标支持 `x12.11 y11.11大大的asadasd`；智能模式按解析后的数值判断重复。没有游戏进程/前台检测。

## 地图

两图 Bakurani / Ozeti；左键拖动空白区域平移、滚轮缩放，点击放置当前选择的炮位/目标，拖动标记实时更新 HUD。“定位两点”可快速回到射击区域。地图默认设置目标；设置炮位需点击“设炮位”。

离线包包含上游 0–4 级瓦片（最高基础分辨率 4096×4096）；可继续放大，但超过原图精度时会变模糊。0–7 级全量高清瓦片尚未捆绑。切换地图直接恢复该图坐标，无需确认。两图包含上游 Tower 编号；点击 Tower 标记可直接选为目标。

## 数据与限制

- 射表与两图参数固定于上游提交 `c3252c9d24a22d1aad5d3fa4408807aef591bb56`。
- 迫击炮 132–684 m；SPH-2 780–2629 m，分别显示低抛和高抛密位。
- 使用默认平地射表；不启用实验性高差与车体倾斜修正。
- 配置保存在程序目录的 `UserData/settings.json`；地图浏览缓存也位于 UserData。
- 目前没有多人房间、OCR 或自动游戏操作。
- 游戏内焦点、反作弊兼容性尚未验证，不能视为官方批准。

## 构建与验证

运行项目根目录 `build.ps1`：使用 `.tools/dotnet` 便携 SDK；缓存落在 `.tools`；编译、自测、上游比对后发布到 `app`。

`--verify` 为开发用演示集成验证：加载两图、测试 WebView2/C# 状态同步并在 `app/Verification` 输出日志及原生界面渲染图。它不操作系统剪贴板，因此测试通过不代表已通过游戏实机验证。
