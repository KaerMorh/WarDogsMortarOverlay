# WarDogs Overlay 0.6.3

联机开发分支使用 **Go WebSocket 服务端 + C# 客户端**，新增模块在独立可拖动窗口中。继续开发请先阅读 [联机开发方案](docs/联机开发方案.md)、[消息协议](docs/联机协议.md) 和 [开发进度](docs/联机开发进度.md)。使用 `build-multiplayer.ps1` 构建到 `artifacts/multiplayer/`，不覆盖下方稳定版 `app/`。

Windows 桌面火力计算器：C# / WPF HUD + WebView2 离线交互地图。

## 启动

打开 `app/WarDogsOverlay.exe`。发布目录自带 .NET 运行时；电脑需安装 Microsoft Edge WebView2 Runtime（开发机已具备）。默认只显示 HUD。按住标题、数字或空白区域拖动；控制面板内可切换炮种、地图和输入模式，直接读取炮位/目标或暂停。点右上角“简化”切为三组数字与操作按钮，同位置“还原界面”返回正常面板，点“点化”收为 40×40 小圆球，单击圆球展开。点“设置”即可在 HUD 内设置快捷键、大小、背景浓度，或手动输入坐标。点击顶部独立“大地图”按钮即可打开桌面地图。关闭主窗口仅隐藏地图；“退出应用”才会退出。

演示：`app/WarDogsOverlay.exe --demo`。演示带两组示例坐标，不读取剪贴板、不保存配置；此时 HUD/地图可交互，快捷键仍会注册。

## 输入模式

- 智能（默认）：炮位/目标动作先读取当前剪贴板，不合适或重复时转为等待；等待成功接收一次后回到就绪。炮位等待再按炮位键取消。
- 连续目标：设置炮位后每次复制坐标更新目标。
- 精确手动：仅按动作时读取。也可在主窗口/HUD 手动输入 X/Y。

快捷键可在 HUD 设置或主窗口独立“设置”页修改、录入、清除。初始便捷绑定：炮位 Ctrl+Alt+1、目标 Ctrl+Alt+2、停止恢复 Ctrl+Alt+P、HUD Ctrl+Alt+H、模式 Ctrl+Alt+M、地图 Ctrl+Alt+G。冲突只显示在近期提示，不弹窗。

坐标支持 `x12.11 y11.11大大的asadasd`；智能模式按解析后的数值判断重复。没有游戏进程/前台检测。

## 地图

两图 Bakurani / Ozeti；左键拖动空白区域平移、滚轮缩放，点击放置当前选择的炮位/目标，拖动标记实时更新 HUD。“定位两点”可快速回到射击区域。地图默认设置目标；设置炮位需点击“设炮位”。

离线包包含上游 0–4 级瓦片（最高基础分辨率 4096×4096）；可继续放大，但超过原图精度时会变模糊。0–7 级全量高清瓦片尚未捆绑。切换地图直接恢复该图坐标，无需确认。两图包含上游 Tower 编号；点击 Tower 标记可直接选为目标。

## 数据与限制

- 射表与两图参数固定于上游提交 `c3252c9d24a22d1aad5d3fa4408807aef591bb56`。
- 迫击炮 132–684 m；SPH-2 780–2629 m，分别显示低抛和高抛密位。
- 使用默认平地射表；不启用实验性高差与车体倾斜修正。
- 配置保存在程序目录的 `UserData/settings.json`；地图浏览缓存也位于 UserData。
- 目前没有多人房间、OCR 或自动游戏操作。
- 游戏内焦点、反作弊兼容性尚未验证，不能视为官方批准。

## 构建与验证

运行项目根目录 `build.ps1`：使用 `.tools/dotnet` 便携 SDK；缓存落在 `.tools`；编译、自测、上游比对后发布到 `app`。

`--verify` 为开发用演示集成验证：加载两图、测试 WebView2/C# 状态同步并在 `app/Verification` 输出日志及原生界面渲染图。它不操作系统剪贴板，因此测试通过不代表已通过游戏实机验证。

## v0.3 记录与可读性

炮位、目标操作及地图切换、模式切换按钮直接显示已绑定快捷键。提示框使用不透明深色底，数字、小字和状态使用独立深色底衬；调低面板背景浓度不会降低信息层的可读性。

本次启动的历史记录按时间倒序保存：蓝色炮位、橙色目标、灰色普通提示。坐标记录包含坐标、地图、炮种、来源，以及所有直线距离不超过 200 m 的 Tower 及方向、距中心距离（坐标单位 × 100 m；北为 +Y）。无附近 Tower 则明确标注。拖动地图只记录最终落点。

正常 HUD 的最新记录下方可以展开记录列表；HUD 设置 → 本次记录使用相同列表。点击坐标记录恢复相应炮位或目标；跨图记录自动切回对应地图。恢复炮位若改变位置，会清除当前目标；恢复坐标保留当前炮种。历史仅属于本次启动，不写入配置文件。

## v0.4 悬浮窗与小球

设置 → 悬浮窗外观新增“按键背景不透明度”和“数值 / 信息背景不透明度”，范围 0%–100%，不改变文字本身透明度。简化模式不显示快捷键标签（鼠标提示仍保留），炮位、目标、暂停、炮种、地图、模式六个按钮共用一行。正常和简化模式只要存在目标就显示当前目标坐标，不依赖炮位或射程。

小球上右键可设置炮位、选定目标、暂停恢复、选择模式 / 地图 / 炮种、打开大地图或设置、手动输入与恢复历史、隐藏 HUD 和退出。菜单或外观设置中的“小球极简化”默认开启，开启后在小球右侧以完全透明背景显示例如：141(m) 839 MIL 45.0 度。SPH-2 仍按低抛 / 高抛顺序显示；无有效值时用 — 占位，不保留旧密位。
## v0.5.0 默认外观与安装

本次将当前目标坐标常驻显示；超程或尚未设置炮位时也显示。默认不透明度取自本地已确认配置：面板 0.5683815809559255（约 56.84%），按键 75%，数值 / 信息背景 75%。旧用户已保存的设置继续优先使用；新配置默认开启小球读数。小球文字默认为蓝色 #91C5FF，支持蓝 / 白 / 橙 / 绿预设及任意 #RRGGBB 自定义颜色。

下载安装包：https://github.com/KaerMorh/WarDogsMortarOverlay/releases/latest

安装包面向 Windows 10/11 x64，默认安装在当前用户的 LocalAppData/Programs/WarDogsOverlay，支持自定义安装位置、开始菜单入口、可选桌面快捷方式和卸载。自带 .NET 与两图离线瓦片；缺少 WebView2 时会运行微软引导安装器，此步骤需要联网。升级保留 UserData；安装包不包含开发者坐标、配置、地图缓存或验证截图。

构建安装包：准备 Inno Setup 6 后运行 `./build-installer.ps1 -Iscc <ISCC.exe 路径>`，或使用项目 `.tools/inno/ISCC.exe`。构建脚本将从微软下载并校验 WebView2 引导安装器签名。成品与 SHA-256 位于 `artifacts/releases`。

## v0.6.0 软件更新

设置顶部提供检查更新、下载安装包、取消下载和重启安装。默认启动后后台检查；发现新版时，HUD、大地图和小球右键菜单的设置入口显示小红点。升级保留 UserData，并备份设置；不强制退出或重启电脑。更新清单验 RSA 签名，安装包验大小与 SHA-256。

0.5.0 和便携版用户需要手动安装本版一次。开发与发布步骤见 [自动更新与发布指南](docs/自动更新与发布指南.md)。

## v0.6.1 更新流程测试

此版本用于验证 0.6.0 的检查更新、小红点、下载和重启安装流程；功能保持一致。更新完成后，设置中的当前版本应显示 0.6.1，原有设置继续保留。

## v0.6.2 单实例与更新缓存

同一 Windows 会话禁止双开，再次启动唤回已有 HUD。更新区域与下方菜单通过卡片及分隔线区分。下载成功的包在下次启动时离线验签和验哈希后恢复；联网检查可复用旧版留下的相同包。已安装或被替代的更新包、损坏包、未完成下载会清理，保留日志及设置备份。没有签名元数据的旧版遗留包最多保留七天等待联网验证。
