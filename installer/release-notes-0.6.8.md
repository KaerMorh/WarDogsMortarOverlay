# WarDogs Overlay 0.6.8

- 新增默认关闭的 PZH 自动装弹实验功能：在 SPH-2 模式下按换弹键，识别四个方向箭头并依次输入，最多提交四组。可在设置中调整换弹键、识别区域和时间参数；Esc 可取消。
- 设置中的“测试识别”与“框选识别区域”会等待下一次换弹键，无需预先绑定游戏窗口或等待倒计时。测试识别只显示结果，不发送方向键。
- 测试功能中的连接功能与自动装弹可分别开启；自动装弹勾选后立即生效并展开设置。
- 正常与简化 HUD 仅在已开启自动装弹且使用 SPH-2 时显示执行状态和最近识别方向。
- 自动装弹只接受稳定的四个白色箭头；下一组即使方向完全相同也可直接继续，无需捕获短暂的绿色/红色中间帧。再次按换弹键会立即打断旧流程并开始新流程。
- 更换炮位时自动清空旧倾斜和 XY 校准及补偿，打开中的校准窗口会同步到新炮位，可直接录入新样本。
- 新增默认关闭的 DeepSeek OCR 实验功能：在游戏地图界面按 Ctrl+1 识别并设置炮位，按 Ctrl+2 识别并设置目标；识别期间会在 HUD 消息栏显示独立状态。
- DeepSeek OCR 使用独立设置标签，可配置快捷键和截图区域。API 测试会分别发送文字与内置地图图片，并显示每一步的结果；请求包含防重复触发、12 秒超时和过期结果保护。
- DeepSeek API Key 仅加密保存在当前 Windows 用户的本地配置中，不会写入发行包。设置页提供 API 获取说明与清除按钮。
- 测试功能在设置页改为独立卡片，联机、PZH 自动装弹和 DeepSeek OCR 的开关与入口更易区分；修复 OCR API 密钥输入框无法正常点击输入的问题。

自动装弹尚未完成游戏内实测；方向输入是否被游戏接受、连续相同组合的颜色反馈和完成反馈仍需验证。达到四组上限仅表示已提交输入，不代表游戏确认装弹成功。

DeepSeek OCR 已通过解析、密钥明文保护、文字请求和内置图片请求测试；真实游戏、多显示器与不同 DPI 下的截图区域仍需实机确认。调用 DeepSeek API 会产生由服务商计费的请求。
