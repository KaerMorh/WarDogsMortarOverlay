## v0.5.0

- 正常和简化 HUD 常驻显示当前目标坐标，超程或未设置炮位时也可查看。
- 默认不透明度：面板约 56.84%，按钮 75%，数值背景 75%；已有配置继续保留。
- 小球极简读数默认开启，文字支持四种预设及 #RRGGBB 自定义颜色。
- 包含近期 HUD 改进：单行六键、小球操作菜单、Tower 方位距离及可点击恢复的坐标历史。
- 提供 Windows x64 安装包，自带 .NET 和离线地图；缺少 WebView2 时需联网安装该组件。

安装：下载 `WarDogsOverlay-0.5.0-win-x64-Setup.exe` 并运行。支持选择目录、创建快捷方式和卸载；升级保留已保存配置。

验证：267 项核心断言、442 个距离 / 1326 次上游射表分支比对；应用集成和安装 / 升级 / 卸载检查。
