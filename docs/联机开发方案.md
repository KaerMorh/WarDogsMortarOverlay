## 用户已确认的产品规则

- 房间码入房，不存在即创建；可启动自动加入上次房间；成员平权，独自在房等待。
- 本地预设 Callsign 和角色。炮兵也能发布任务；侦察兵是精简显示模式。
- 发布任务按独立键后等待下一次复制。无效文本继续等待；再次按键取消；有效坐标发布一次退出。发布不改变自身炮位和解算目标，连续输入模式也不能同时消费该复制事件。
- 炮位自动共享。解算目标默认自动共享，可在本地关闭；关闭后不再发送目标和解算状态，不撤回最后公开状态，不发送关闭提示。对端文案为“正在解算 xxx”。重新开启发送最新状态。
- 每个成员最近三个任务，按时间排序；更多记录保存在本机设置的本次记录里。与单机历史共用 100 条限额，启动清空，不跨启动持久化历史。
- 得到有效解算结果才标记解算过，显示谁曾解算、谁正在解算。关闭共享不公开这些新状态。
- 离线保留三分钟；同 UID 重进替换旧条目，不恢复旧任务。角色从本地预设读取。新建房间为空。
- UID 持久化、界面不显示；同 Callsign 允许重名，完全同名添加 #n。
- 地图不一致提醒；Draw / Marker 暂不实现。

## 技术方案

服务端 Go 标准库 net/http + github.com/coder/websocket；客户端继续 WPF / C#，使用 ClientWebSocket。JSON 消息带协议版本；不使用 SignalR、数据库、Redis。Docker Compose 单实例，HTTPS 由 Caddy 终止。服务器只校验和转发状态，不做射表解算、不传地图瓦片。

服务端房间状态统一加锁；连接独立有界发送队列，慢客户端断开，不阻塞房间。每次入房下发完整快照，后续广播成员更新/移除；主动任务带 ID 幂等。连接读大小、入房超时、心跳、频率、房间和成员数均受限。

客户端网络层独立于 WPF，接收消息通过 Dispatcher 交给界面。断线后指数退避重连，每次连接是新会话；旧连接消息不得污染新会话。状态变化合并至最多 5Hz，发布立即发送。断线期间不积压发布任务，提示失败由用户重新发布。

## 身份与生命周期

首次正常加入房间时通过 Guid.NewGuid() 生成 UUID，原子写入 UserData/identity.json，之后启动/入房复用；升级保留，发行包排除，演示不持久化。身份文件损坏不得静默复用非法 ID。复制身份文件等于复制身份，不是硬件绑定。UID 是标识而非认证凭据，第一版仅适用于知道房间码的可信同伴，不提供账号认证。

服务端生成会话 ID 和房间实例 ID，入房同 UID 替换旧连接并清空其任务。旧连接断开只能标记自身会话离线，不可影响替换者。在线仅一人不销毁；最后一个离线成员三分钟过期后销毁；服务重启所有房间清空。重进时客户端仍可从本地设置发送当下炮位和允许公开的目标，但不重放旧任务。

同名标签由服务端按入房顺序确定。历史身份按 UID 保存，同时记录当时显示名，避免改名或重复名造成归属混淆。

## 任务与历史

主动发布每次产生 UUID，同坐标再次主动发布是新任务。服务端时间/递增序号排序，最新在上。按地图与坐标数值（六位小数规范化）匹配解算，不能按屏幕两位小数字符串匹配。任务选择携带 taskId；坐标匹配也覆盖手动解算。

任务三条窗口与本地 100 条历史分离。远端目标/炮位状态不反复挤入历史；任务首次收到才记一次，状态更新原条目。新入房只接收当前快照，不补发服务器全部历史。重连快照按任务 ID 去重。超出显示窗口的本地任务保留已有解算记录，后续公开解算状态仍按坐标更新本机保留任务。

现状：Controller.History 是本次运行内存列表，但 AddHistory 尚无限额。本次补统一 100 条裁剪。禁止直接调用本地 SetTarget 来处理收到的房间消息；仅用户选择时调用。

## UI 和输入

2026-09-08 用户后续调整（覆盖先前把任务嵌入 HUD 的布局方案）：新增任务选择模块放在独立、可拖动窗口，原 HUD 不做大改。先实现基本功能，界面精细化留待后续。正常/简化/小球的本地解算布局维持原状；联机窗口使用原生标题栏拖动，可调整大小，关闭窗口不退出房间。

设置新增服务地址、房间码、Callsign、角色、启动自动进入、目标自动共享；角色切换立即更新成员。独立联机窗口列表可滚动，每人三条，展示离线/角色/炮位/正在解算、任务解算者。侦察模式默认收起成员详情、突出任务；当前不自动改变原 HUD 的解算布局。

任务窗口基本交互：独立可配置开关、上一条、下一条、确认和关闭；每人任务按时间倒序，按任务 ID 保持高亮，删除所选任务后清空选择，禁止自动选中另一任务。高亮与当前解算目标区分；跨图选择先提醒确认。小球/右键/设置提供打开入口，首次入房自动打开，普通重连不强制重开。点击解算后窗口保持打开。界面更新合并到最多每秒五次，不逐条广播重建控件。
