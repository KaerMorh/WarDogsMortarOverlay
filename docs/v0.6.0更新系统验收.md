# v0.6.0 更新系统验收

2026-09-07，本机 Windows x64。

## 已通过

- 267 项原有核心断言。
- 32 项更新断言：RSA 签名及错误密钥/篡改拒绝、版本比较及禁止降级、清单 URL/大小/哈希校验、损坏包拒绝、便携版提示、取消与重试、网络失败保留已知新版。
- 442 个距离、1,326 项上游 JavaScript 结果比对。
- 44 项 WPF/WebView2 集成检查：现有地图/HUD/历史交互、设置中的更新区域、正常/简化/小球/大地图的红点、无更新时红点消失；原生截图已检查。
- 独立测试 AppId 的 0.5.0 → 0.6.0 安装升级：中文和空格路径、等待进程退出、安装包锁定及二次哈希校验、settings.json 备份、UserData 保留、自动重启、卸载测试副本。
- `.gitignore` 排除工具链/签名私钥、发布包、用户配置、日志、验证截图和环境凭据；更新公钥保留在版本控制中。

## 复现

```powershell
pwsh -File ./build.ps1
./app/WarDogsOverlay.exe --verify --verify-exit
pwsh -File ./build-installer.ps1 -SkipBuild
pwsh -File ./create-update-manifest.ps1
```

集成日志与截图位于 `app/Verification`。安装升级测试脚本为 `tests/installer-update-smoke.ps1`，参数 `-OldPayload` 传入已验证的旧版干净发布目录；证据保存在 `artifacts/update-smoke-*`。此脚本使用独立应用标识，不覆盖正式安装身份。

## 范围

本版提供正式版全量更新，不提供增量下载、断点续传、自动降级或安装事务回滚。0.5.0 用户仍需手动安装 0.6.0 一次。清单签名不是 Windows 代码签名。安装中断时可重新运行安装包修复，设置备份用于恢复。
